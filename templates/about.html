Application Overview

Welcome to Django Student Management Web App. This system is designed as a modern, scalable web application built with Django and optimized for serverless deployment on Vercel.

Features include dynamic template rendering using SB Admin 2, student data management with PostgreSQL/SQLite, security optimizations for CSRF & CORS, and static file serving using WhiteNoise.

Key Highlights:
  • Serverless Architecture: Optimized for Vercel Python runtime using WSGI entrypoints.
  • Database Flexibility: Support for local SQLite development & cloud PostgreSQL (Neon).
  • Responsive UI: Built with Bootstrap 4 & SB Admin 2 design tokens.
  • WhiteNoise Integration: Fast static asset compression & delivery.
Technology Stack
Python 3.12+ Django 6.0 PostgreSQL / Neon Vercel Serverless WhiteNoise SB Admin 2
